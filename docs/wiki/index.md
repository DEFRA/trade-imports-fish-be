# Trade Imports Fish Backend

Welcome to the Trade Imports Fish Backend documentation. This is a Spring Boot 3.5 application built with Java 25 that provides backend services for the Trade Imports Fish system.

## Overview

The Trade Imports Fish Backend is responsible for:

- Managing fish import compliance data
- Handling authentication and authorization
- Processing and storing import information
- Providing REST APIs for frontend applications
- Integration with external services

## Technology Stack

- **Java 25** - Programming language
- **Spring Boot 3.5** - Application framework
- **MongoDB** - NoSQL database
- **Maven** - Build tool
- **Docker** - Containerization
- **AWS** - Cloud services (S3, SQS via Floci)
