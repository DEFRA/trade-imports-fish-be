# Getting Started

Welcome to the Trade Imports Fish Backend! This section will help you get up and running with the project.

## Prerequisites

Before you start, ensure you have the following installed:

- **Java 25** or later
- **Maven 3.8.0** or later
- **Docker** and **Docker Compose**
- **Python 3.11+** (for documentation development)
- **Git**
