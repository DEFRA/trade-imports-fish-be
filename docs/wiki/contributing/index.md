# Contributing

Welcome! We appreciate contributions to the Trade Imports Fish Backend.

## Before You Start

- Read the [Contributing Guide](guide.md)
- Understand the [Code Standards](../architecture/index.md)
- Review the [Pull Request Process](pull-requests.md)

## Contribution Areas

- **Bug fixes**: Report and fix issues
- **Features**: Implement new functionality
- **Documentation**: Improve and expand documentation
- **Tests**: Add and improve test coverage
- **Performance**: Optimize code and queries

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature`
3. **Make your changes**
4. **Write tests** for your changes
5. **Follow code standards**
6. **Commit with clear messages**
7. **Push to your fork**
8. **Open a Pull Request**
